# ACPID - Advanced Configuaration and Pawer Interface Daemon

[https://wiki.archlinux.org/title/Acpid](https://wiki.archlinux.org/title/Acpid)

This detects events for a bunch of power/device related systems, such as screen brightness, power buttons, and plugging in headphones.

I'm using this to set the sound card profile correctly when headphones are plugged in.
